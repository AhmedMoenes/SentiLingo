Appendix A — Glossary

TermMeaning in this document
Franco-Arabic (Arabizi)Arabic written in Latin letters, with digits standing for Arabic sounds (e.g. 3 = ع, 7 = ح), as in el service 7elw.
Code-switchingMixing two or more languages or scripts in one message.
MSA / Egyptian ArabicModern Standard Arabic, the formal written variety / the everyday Arabic dialect of Egypt.
TF-IDFTerm frequency–inverse document frequency: weights a word by how often it appears in a text, discounted by how common it is across all texts.
N-gramA sequence of n consecutive words or characters, used as a feature.
BiLSTMA bidirectional Long Short-Term Memory network: a recurrent model that reads text in both directions.
Transformer / fine-tuningA neural architecture based on self-attention / further training a pretrained model on labelled task data.
Macro-F1The average of the per-class F1 scores; every class counts equally, so minority classes are not ignored.
Confusion matrixA table of predicted against true classes, showing which classes the model confuses.
MLflowAn open-source platform for tracking experiments and registering models.
CRISP-DMA standard data-mining process: business understanding, data understanding, data preparation, modelling, evaluation, deployment.
MoSCoWA prioritisation scheme: Must, Should, Could, Won't (this time).
